# 🧮 Professional E-commerce Margin & VAT Calculator

A production-ready, highly responsive web application designed for retail and e-commerce store owners to calculate accurate sales prices, handle complex multi-currency supplier costs, and instantly evaluate true profit margins.

## 💡 Business Value & Problem Solving
Most small-to-medium webshop owners struggle to calculate their exact profit margins because supplier costs involve hidden variables: international exchange rates, bundled shipping costs, packaging materials, and payment gateway fees. 

This tool bridges the gap between raw accounting data and a clear, profitable pricing strategy in seconds—tailored specifically for non-technical users.

---

## 🚀 Key Technical Features
* **Multi-Currency & Exchange Rate Handling:** Seamlessly processes EU purchases in EUR with real-time conversion into DKK.
* **Automated Cost Distribution:** Dynamically calculates proportional shipping costs per item based on total order size.
* **True Profit Calculation:** Subtracts variable overheads (packaging, payment gateway percentages, and state VAT) to reveal the *real* bottom-line margin.
* **Optimized Workflow ("Next Item" State Reset):** Built with rapid retail data entry in mind, allowing users to clear and process sequential inventory items instantly without manual field deletion.
* **Defensive UI & Error Handling:** Gracefully handles invalid inputs, empty strings, and NaN edge cases using robust parsing logic.

## 🛠️ Tech Stack & Architecture
* **Frontend Library:** React (Functional Components & Hooks)
* **Type Safety:** TypeScript for robust state and data flow management
* **Build Tool:** Vite for instantaneous hot-module replacement and optimized production builds
* **Styling & UX:** Custom responsive inline styling, mobile-first grid layout, and professional data-visualization cards tailored for desktop and tablet usage in physical retail environments.
